# Roadmap

English · [Tiếng Việt](ROADMAP.vi.md)

Version plan for ColimaX. The status of each item is defined by [FEATURES.md](FEATURES.md); V / C / R scores (value / complexity / risk, on a 1–5 scale) come from [AUDIT.md](AUDIT.md). Before taking on an item, update its status in FEATURES.md as described in [AGENTS.md](../AGENTS.md).

## 1.0.0 — first release

Feature-complete in the codebase; every item in [FEATURES.md](FEATURES.md) has release 1.0.0. Scope:

- Runtime: Colima VM and profile management; CPU / memory / disk / VM type / mounts / Rosetta / k3s configuration; Docker endpoint taken from `colima status --json`; real-time updates.
- Containers: actions, details (health, OOMKilled, exit code, resource limits, env with secrets masked), logs and export, exec, Terminal.
- Compose: projects from labels and directories, project and per-service actions, logs, validate, config.
- Images / Volumes / Networks: full management, image architecture, network connect / disconnect, vulnerability scanning with Trivy / Docker Scout.
- Backup: volume `.tar` with SHA-256 manifest and verification before restore; MySQL / MariaDB / PostgreSQL / Redis dumps and restore; schedules with retention; Elasticsearch / OpenSearch snapshots.
- Diagnostics & Security: runtime checks, Apple Silicon, read-only security audit, port conflicts.
- Monitoring & Storage: per-container resources, background sampling with history and threshold alerts, disk usage analysis and cleanup.
- Tools: network / Compose topology, local domains (`*.localhost` via Caddy, local HTTPS).
- App: menu bar, Preferences, Setup Assistant, ⌘1…⌘9 shortcuts, cancellation of long-running operations, English and Vietnamese.
- Engineering: service protocols with in-memory fakes, per-screen models, XCUITest UI tests (T6–T10; design in [ARCHITECTURE.md](ARCHITECTURE.md) section 8).

### Before releasing 1.0.0

| Task | Reason | How |
|---|---|---|
| Register the `colimax.dev` domain | The bundle ID `dev.colimax.ColimaX` is based on this domain, and the landing page (`site/`) will be served there | [RELEASE.md](RELEASE.md) section 2.5 |
| Apple Developer Program + certificates | Required for Developer ID signing; without it Gatekeeper blocks the app on other machines | One-time setup per [RELEASE.md](RELEASE.md) section 2 |
| GitHub repository + secrets | CI and the Release workflow need the repository and certificate / notarization secrets; private vulnerability reporting is enabled with the repository | [RELEASE.md](RELEASE.md) section 2.4 |
| Beta `1.0.0-beta.1` | Collect bugs from real users before the final release | [RELEASE.md](RELEASE.md) section 3.2 |

Done:

- Unit, integration (including Elasticsearch and VM lifecycle) and UI tests pass on a real Colima VM; see [FEATURES.md](FEATURES.md#verification).
- Manual UI pass following [TESTING.md](TESTING.md).
- Landing page in `site/` (English + Vietnamese), published by the Pages workflow once the repository exists.
- License: MIT ([LICENSE](../LICENSE)).
- App icon: CX monogram, `Resources/AppIcon.icns` generated by `scripts/make-icon.sh` and bundled via `CFBundleIconFile`.
- Release infrastructure: `scripts/release.sh`, `scripts/make-dmg.sh`, `scripts/notarize.sh`, GitHub Actions CI + Release (draft), issue/PR templates, [RELEASE.md](RELEASE.md). Not yet run for real: requires a Developer ID certificate and the GitHub repository.
